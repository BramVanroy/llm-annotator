# Case studies

Complete research projects built on the library, kept as worked references.
They are larger and more specific than a first-time user needs; start with
[`examples/`](../examples/) instead.

- `model-comparison`: judges three candidate models with an LLM-as-a-judge
  pipeline to pick one for synthetic data generation.
- `wiki-nl-persona-qa`: generates persona-grounded Dutch Wikipedia QA pairs
  with reasoning traces, judges them, and builds an SFT dataset from the ones
  that pass.
